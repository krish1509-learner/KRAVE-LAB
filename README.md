# KRAVE LAB

A bold, responsive restaurant website for KRAVE LAB, featuring smash burgers, loaded fries, matcha drinks, menu filtering, dark mode, and an interactive shopping cart.

## Features

- Responsive restaurant landing page
- Food and drink menu with category filters
- Interactive shopping cart with quantity controls
- Light and dark themes
- Specials, restaurant story, and visit information

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a web browser.
